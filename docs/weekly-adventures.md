# 自动组队活动、正魔大战与玄骨限额

配置位于副本页的活动配置。五个登录号统一协调占用，未达到境界的号暂不参战。

| 玩法 | 自动目标 | 当前组队方式 |
| --- | --- | --- |
| 猎妖船 | 每人每周5次 | 五号同队，外海优先；逐日船体低于36退近海 |
| 天澜草原 | 每主魂每周2次 | 3–5名元婴以上；低境界号升级后自动纳入 |
| 越京夜行 | 每主魂每周2次 | 五号同队，筑基以上 |
| 阴冥之地 | 每主魂每周2次 | 两名元婴以上；优先安排次数未满的成员 |
| 玄骨遗府 | 每天最多1次，每周最多3次 | 五人结丹以上；先刷新完整背包，选择持有古府寻踪珠的队长 |
| 七派密议 | 每个主魂每天最多3局 | 三至五个已配置本机身份；名单确认后开议，按暗通张数更新推断 |
| 正魔大战 | 每个主魂每天出征一次 | 先查本人军情，沿用已有或宗门固定阵营；无阵营跳过 |

猎妖按每个成员的真实船况决定是否继续。满次数的成员可以陪未满成员，所有成员5/5才停止。登船也使用90秒窗口内的限时队列；完整船员名单仍以游戏面板为准，外人抢位时不会给未登船身份发送动作。

三项新周常按真实结算逐人计数，接到“本周有奖次数已满”立即记满。启动时从本周既有消息补齐奖励证据，接到完整名单结算后才释放占用。按上海时间ISO周重新安排，游戏的已满回执优先于本地计数。

天澜按巡哨线索选择斩哨或潜行，一人诱敌，其余人应对圣兽。越京依次去道观、集市、秦府，按灵根分兵，并用真凰符应对有虚招的征兆。阴冥枚举线索允许的路口分布；存在歧义时避开所有可能的阴魂路，死路回执能排除后再尝试另一条路。暴风山的二选一线索仍有游戏本身的不确定性，不保证零损失。

玄骨不购买或兑换门票。无票不占次数；预定开局前持久化当天及当周名额，未知发送或重启不会再花第二颗票。集结面板须确认所有成员“可领奖”才入场，不满足则取消并保留门票。历史真实领奖回执会计入本周限额。

长风保持单独配置。`start.run.rewarded`是有奖资格证据，场地的`status.remaining`可能滞后。按场地保存只读查询，默认限额不因场地读数不同而提高。

七派每日前三局副本奖励，与胜利后每日一次的额外阵营战功分别计数。只有本局关联结算或完整本队名单才能确认奖励；匿名他队散议不会计入。集结名单不符时由发起人散议，收到游戏成功回执后才释放占用。主帅按全部21种内鬼组合及70%暗通概率选择守关组合，其余本机长老投准；不自动试探。

游戏明确回复“这里已经有一场密议了”时，本队未创建房间，自动释放占用并等待空房。别队散议仅用于安排下一次开局，不计入本队奖励；开局尝试至少间隔五分钟，未观察到别队结束时十五分钟后再试。

已吸收上游 `21900044` 适用修复：天澜、越京、阴冥以包含本队发起人的实际出发名单为准；未入队身份释放占用，不再补发加入。阴冥只由实际辨路/感魂者操作，外部队友担任感魂时等待其应招。天澜通过真实诱敌回执确认诱敌者，之后不再让其收兽。未知发送不重发；已证实未发送的动作最多三次、间隔15秒且仅限原轮期限。重启从本地日志恢复已有终局，或等待新鲜更高阶段面板续接。

正魔从本人阵营的“以【战术】应之”提取推荐，不能误用敌方战术。出征不明或重启时先重新查询，最多自动查询三次；不直接重放出征。配置中投效偏好留空，默认跳过无阵营身份。日志群可用 `.正魔 状态 身份ID` 查询记录。

遇到未知结果或同群其他同类队伍时暂停，不重放旧动作。先核对游戏已经结束，再在管理员日志群使用：

```
.周常 确认结束 tianlan/yuejing/yinming/qipai 准确记录号
```

该确认保留原动作和次数证据，五分钟后才允许重新安排。玄骨及猎妖沿用各自原有确认命令。
