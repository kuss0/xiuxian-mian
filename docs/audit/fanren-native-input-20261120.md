# 原生浏览器客户端操作候选

新增独立的单次人工入口 `/api/fanren-client-browser`，支持 `status`、`stop`、`start`；start 需 `send_as_id` 和 `scenario`（inspect、walk、npc、fishing、combat）。没有接入自动调度。

此入口使用正式 Mini App、完整 Chromium、Xvfb 与原始游戏脚本。鼠标点击有实际移动、按下/释放和观察间隔；走路、交互、钓鱼收线和战斗使用浏览器原生键鼠输入，不直接改坐标、时钟、分数、物理参数或调用服务端结算接口。游戏页面照常生成请求与证明。

账号使用已注册的本人 session，通过主服务获取 WebView，核对 `initData` 的账号与页面返回的 `playerId`。任务在主服务持有原洞府共享锁；浏览器退出和收尾后才释放。其他玩法把 loading/running/held 视为占用。发出变更前先保存原始页面生成的 operation ID；未知回包继续 held，不用 UI 胜利或 HTTP 200 充当结算完成。场景操作只保存结构化记录，启动 URL 使用 0600 临时文件并在结束后删除。

`FANREN_ASSET_BUNDLE` 可指定已校验公开客户端素材。缓存仅处理允许的静态路径和版本/当前页面摘要；HTML、登录和 API 始终走真实服务。服务端摘要更新、显式 retry、资源不匹配时回到正常网络。每次返回的素材字节均重新校验 SHA-256。

- 原始洞府场景、男角色 GLB、动画、原生碰撞和镜头在 Linux ARM64 上实际运行。
- 有界面 Chromium 原生输入完成走到炼丹炉、按 E 交互、碰撞后停止、取消后松键和身份变化拒绝继续。16 个可信键盘事件、0 个合成键盘事件；动作来自浏览器输入，无坐标改写。
