## 不应称为已经全自动的部分

上游 `model/fuben/zhengmo.py` 只有每日查询、可选投效、按军情出征和失败重查。
大会报名是本地后加的功能。上游没有劫营选敌、越京/七派每日战功规划、押注或倒戈自动策略。
所以这些缺口不能归咎为“上游已有但没搬”，也不能以“已吸收上游”宣称整个正魔玩法完成。

| 玩法目标 | 已核实规则 | 当前边界 |
| --- | --- | --- |
| 出征 | 每主魂每日一次，军情七成把握 | 按本人军情行动；一次被克制不能证明战术解析错误 |
| 阵营 | 固定宗门或本季投效 | 三个无阵营身份继续按用户要求跳过 |
| 燕家堡大会 | 每季第4天21:00，报名后按战功前5名出战 | 两号已报名；报名不等于入选或领奖，赛果尚未发生 |
| 越京战功 | 副本周奖前2次，正魔通关阵营战功每日+10 | 两套限额须独立；不更改用户每周2次的副本设置，不把周满后的每日战功说成已打满 |
| 七派战功 | 副本每日前3局有奖，胜利阵营战功每日+5 | 现有局数账不代表已取得每日胜利战功 |
| 劫营 | 每日出手3次、同敌1次；须敌对且境界差不超过一大境界 | 无自动选敌与完整日账，未追加陌生攻击目标 |

继续完善收益规划须单独实现战功日账、被动奖励证据、目标选择及拒绝/逃脱处理。
本次修补不新增投效、押注、避战、倒戈或耗尽副本周奖后的额外开局。
