# 修仙日志群安静模式

普通成功、任务进度和等待改为现有持久化摘要，每小时一条，最多5条
折叠明细。正文、身份和收益仍保存在本地日志与原摘要记录中；不改变
游戏发送、模块开关、资源策略或未决游戏状态。

安静模式只在结构化持久化摘要启用时生效。高优先级、人工处理、
失败/异常/未知/未确认结果与带按钮消息保留实时路径；资源数字不会
被识别成HTTP状态码。摘要送达未知仍保留held，不自动重发或回退。
现存181条历史未确认计数未清除，不将它们重新发送。

实现：model/config.py 与 model/runtime.py；默认开关关闭。
生产配置：deploy/xiuxian-notification-quiet.conf，安装到
/etc/systemd/system/xiuxian.service.d/notification-quiet.conf 后重启主服务。
恢复摘要会将next_at推后至当前时间+3600秒，重启不会立即刷旧积压。
回滚只删除该drop-in并恢复旧代码，不删除audit_summary.db。

验证：新用例覆盖小时窗口、原成功/等待合并、关键告警与按钮即时、
错误/未知结果保留、关闭开关/无持久摘要时兼容旧策略，以及未知投递
不重放。通知、摘要存储、显示和投递的定向回归使用隔离DB与模拟发送。
不向Telegram发送测试消息；上线验收依赖自然事件及现有投递回执。
