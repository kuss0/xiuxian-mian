# 红包提醒生产验收（2026-07-28）

## 结论

红包提醒链已完成真实生产闭环：仅在源群出现“金额不少于 50 LDC 的候选指令”和金额、数量一致的成功红包卡后提醒；低金额红包和普通聊天不会触发。该事项可从待验收转为已销号。

## 实现边界

- `model/features/red_packet_monitor.py` 监听 `@ja_netfilter_group`，兼容成功红包卡的多行、全角字符和指令/回包乱序。
- `.发红包 <金额> <数量>` 只建立候选，不单独触发提醒。
- 提醒必须绑定真实 `【LDC 红包】` 成功卡，并严格匹配金额与数量。
- 金额阈值为 50 LDC；成功红包按消息 ID 去重。
- 每个命中红包连续提醒 3 次，并同时投递日志群和独立 Bot 通知渠道。
- 提醒携带原红包消息直达链接，不执行自动抢取或其他游戏操作。

相关实现提交包括 `5213aeb9`、`1a316ff7`、`401d347a`、`36210f5a`、`670f45dd` 和多行成功卡修复 `e1f663cb`。
