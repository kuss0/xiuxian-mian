## 通报

浏览器奖励沿用原有 `normal` 单条通知，只通报真实服务器确认的奖励、重数和结局；同一局号不重复通报。旧 HTTP 奖励通知也补齐了普通优先级及 queued/confirmed/unconfirmed/unknown 状态。通知失败、取消或通知保存失败不应把业务 done 变成 held，也不应重打副本；历史完成记录不自动补发。

`normal` 的实际实现绕过低优先级摘要明细预算，等待 Telegram transport；默认 low 摘要以前可能挤掉长风奖励行。历史整批投递哈希不能证明某一条长风明细已送达。
