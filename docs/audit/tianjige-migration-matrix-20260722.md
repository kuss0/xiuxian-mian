## 暂不迁移

- `locked`：天星宗、阴罗宗、合欢个人心印等只能在宗门和身份条件满足时由对应模块调用，
  不能做全身份通用入口。
- `external`：宗门灵圃、外府游戏、琉璃问心塔继续走各自 MiniApp adapter，不走天机阁命令提交。
- `pending`：突破、宗门任务/外交、万宝楼/拍卖尚未由服务端完成页面迁移。
- `group_only`：副本、斗法、目标咒术/双修、牌局和管理命令依赖公开群上下文，保持群内。
- 总览型 `integrated`：状态、闭关、炼丹、储物袋/法宝、洞府、宗门、小世界、野外等已有专用
  页面/API，应直接解析结构化字段，不退化成天机阁文字命令。
